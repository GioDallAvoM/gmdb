# Gmdb — Gio's Movie DataBase

Copia pubblica, in sola lettura, del database personale dei film di Giovanni.
Sito: https://giodallavom.github.io/gmdb/

La versione di lavoro (dove si votano i film) è la pagina Gmdb su claude.ai.
`index.html` viene rigenerato da `strumenti/build.py` a partire da quella pagina
e dai dati del suo archivio; non modificarlo a mano.
